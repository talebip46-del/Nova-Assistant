LOCAL MODELS - the categorized layout (v6.1)
============================================
Drop model FILES here:
  local/*.gguf            -> GENERAL models (every module)
  local/code/*.gguf       -> Nova Code / Flow only
  local/voice/*.onnx      -> Nova Voice (Piper voices)
  local/photo/*.safetensors -> Nova Photo (A1111/ComfyUI)
Ollama models need NO folder - they are read from Ollama.
Nova Flow sees ALL folders.
